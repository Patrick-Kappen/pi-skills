# Git hooks and global hooks

The repository works with and without a global `core.hooksPath`.

The owner's machine has one: central hooks, set through an `includeIf` for `~/work/**` and
`~/private/**`. Other machines may have none. Those central hooks:

- in pre-commit, run `nix fmt -- --fail-on-change <staged files>` when `flake.nix` exists. The flake's
  formatter must therefore be treefmt (`pkgs.nixfmt-tree`);
- in pre-push, run gitleaks over the pushed commits, and `nix flake check` when
  `git config zd.flakeCheck` is true;
- then call the repository's `.githooks/<hook>` if it exists, else `<git-common-dir>/hooks/<hook>`.

devenv's default installer refuses to install prek when a global `core.hooksPath` exists, or it
points `core.hooksPath` at `.git/hooks`, which would bypass the central hooks. So the scaffold:

1. tracks `.githooks/pre-commit`, `commit-msg` and `pre-push`. Each runs
   `.devenv/profile/bin/git-hook <type>`, which is prek with the config generated by devenv;
2. replaces the task `devenv:git-hooks:install`. It only sets `core.hooksPath=.githooks` when no
   hooks path is configured, so machines without central hooks also work;
3. skips `nix flake check` in its own pre-push when `zd.flakeCheck` is true, because the central hook
   already ran it.

## Symptoms

| Symptom | Cause | Fix |
|---|---|---|
| `pre-commit: run 'devenv shell' once` | `.devenv/profile` is missing in this checkout or worktree | `devenv shell` |
| `Refusing to install hooks because core.hooksPath ...` | The install task was not replaced | Restore the `tasks."devenv:git-hooks:install"` override |
| `formatter ... needs treefmt` | `flake.nix` without a treefmt formatter | `formatter = forAllSystems (pkgs: pkgs.nixfmt-tree);` |
| convco rejects `fixup!` | Fixup commits are not Conventional Commits | `SKIP=convco git commit --fixup ...`, then autosquash |
| Hooks run twice | `core.hooksPath` is set locally and globally | `git config --local --unset core.hooksPath` |
