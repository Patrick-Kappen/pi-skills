# 1. Scope

1. Find the skill: `ls skills/` in the pi-skills repository (`~/private/pi-skills`). Read its
   `SKILL.md` and skim the guides and references, so you can judge the report later.
2. If the skill is not in the repository, stop: move it in first with the skill-create skill
   (it has a step for importing an existing skill), then come back.
3. Ask the user, in **one** question, what is not already clear:
   - the skill;
   - what to look at: everything, or a known problem ("it keeps skipping the dry run");
   - the period (`--since`), if older sessions used an older version of the skill;
   - changes the user already wants, independent of the sessions.
4. Note the skill's current `metadata.version`.
